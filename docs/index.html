php2shell checker

CVE-2026-109618 / CVE-2026-109619: unauthenticated remote code execution in PHP itself. Every PHP site is in scope: WordPress, Laravel, Drupal, Joomla and custom code. Read the full write-up.

Passive check: it reads public headers and a few common phpinfo URLs. It sends no exploit payloads and stores nothing.

Deeper check: run it on your server

A website scan can't see distro backports, Docker containers or signs of an attack. Run this on the server (read-only, changes nothing):

curl -fsSL https://raw.githubusercontent.com/arifulislamat/php2shell/main/check.sh | sudo bash

Or scan a site from your own computer:

curl -fsSL https://raw.githubusercontent.com/arifulislamat/php2shell/main/check.sh | bash -s -- https://example.com

Shared hosting with no SSH? In WordPress, open Tools → Site Health → Info → Server to see the PHP version, or ask your host.
